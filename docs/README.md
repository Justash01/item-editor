# Item Editor documentation

Three guides, depending on what you're after. They're also on the
[website](https://jstash.dev/item-editor/docs) if you'd rather read them there.

**[Editor guide](editor.md)** covers the menus, from opening the editor to
editing a whole set of gear at once, the wand and every setting.

**[Abilities](abilities.md)** covers making items do things by themselves, and
writing abilities out by hand.

**[Command reference](commands.md)** covers every command with its arguments
and edge cases, plus reference tables for properties, item data documents and
slot names.

New to it? Start with the [README](../README.md) for install and a quick look at
both sides.
