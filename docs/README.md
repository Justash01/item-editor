# Item Editor documentation

Two guides, depending on how you're using the add-on.

**[Editor guide](editor.md)** covers the menus: opening the editor, what each
item screen does, blocks and signs, editing a whole set of gear at once, the
clipboard, undo, the wand, and every setting.

**[Command reference](commands.md)** covers the commands: selections and groups,
then each command with its arguments and the edge cases, plus reference tables
for properties, item data documents and slot names.

New to it? Start with the [README](../README.md) for install and a quick look at
both sides.
